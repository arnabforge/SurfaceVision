# SurfaceVision 

### AI-Powered Road Pothole Detection and Severity Analysis

SurfaceVision is a deep learning-based computer vision
project designed to detect road potholes and classify
their visual severity into Low, Medium, and High categories.

##  Objectives

- Detect potholes in road images using YOLO.
- Classify detected potholes using a CNN.
- Evaluate detection and classification performance.
- Build an interactive application for road damage analysis.

##  Technology Stack

- Python
- PyTorch
- YOLO
- OpenCV
- Streamlit
- Git and GitHub

##  Project Structure

- `src/` - Application source code
- `notebooks/` - Experiments and data exploration
- `tests/` - Automated tests
- `docs/` - Project documentation

##  Project Status

Currently in the initial development phase.

##  Disclaimer

Severity predictions are experimental and should not be
treated as measurements of pothole depth or certified
road safety assessments.
